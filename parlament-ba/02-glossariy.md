# Глоссарий и границы данных

| Термин | Значение для команды | Пример или основание |
|---|---|---|
| Федеральное Собрание | Парламент РФ, состоящий из двух палат — Совета Федерации и Государственной Думы. | Конституция РФ, ст. 94–95. |
| Депутат ГД; сенатор РФ | Носители публичных полномочий в соответствующих палатах. Выражение «депутат СФ» исправлено. | N01, N11. |
| Субъект права законодательной инициативы | Лицо или орган из конституционного перечня. Уполномоченный оператор может технически передать его пакет. | N02. |
| Законопроект → принятый ГД федеральный закон | До принятия обсуждается проект. В СФ поступает уже принятый ГД закон. Единство истории обеспечивает ID дела. | N03–N06. |
| Законодательное дело | Связанный комплект проекта, редакций, заключений, поправок, решений и сообщений палат. | F01–F07. |
| Карточка; документ; версия | Карточка содержит реквизиты; документ имеет устойчивый ID; версия фиксирует содержание на конкретный момент. | F09. |
| Форма | Версионируемое описание реквизитов и переходов для вида документа. Один экземпляр документа использует определённую версию формы. | F10. |
| Стадия; статус; событие | Стадия относится к процедуре, статус — к объекту, событие фиксирует факт перехода и его основание. | «Второе чтение» / «на экспертизе» / «заключение получено». |
| Поправка; заключение; постановление | Предложенное изменение к тексту; позиция рассматривающего органа; акт палаты, оформляющий принятое решение. | N04–N07. |
| Заседание; вопрос; сессия голосования | Заседание включает вопросы. Вопрос относится к конкретной редакции. Повторное голосование образует самостоятельную сессию по тому же вопросу. | F15–F17. |
| Протокол; стенограмма | Протокол фиксирует результат и процессуальные реквизиты; стенограмма передаёт ход выступлений. Объекты связаны с заседанием и имеют собственный режим доступа. | И 08:08, 11:36; N05, N10. |
| Закрытое заседание; тайное голосование | Первое ограничивает участие и раскрытие материалов, второе защищает индивидуальный выбор. Это два разных признака в модели данных. | N10–N11. |
| Право; роль; назначение | Одна операция над типом объекта; именованный набор таких операций; связь пользователя с ролью в области и на срок. | Т2–6; F11. |
| Область; основание | Палата, подразделение, форма или конкретное дело, к которым относится назначение; документ, подтверждающий назначение либо полномочие. | З; F11–F12. |
| Аутентификация; авторизация; подписание | Установление личности; решение о допуске к действию; выражение воли по конкретной версии. | И 02:29; Т7; N13. |
| Публикация результата; официальное опубликование | Сообщение о ходе заседания и юридически значимое событие опубликования полного текста акта учитываются раздельно. | N12; F18. |
| Архивный экземпляр; временная копия | Первый используется для хранения и выдачи; вторая обслуживает доставку до подтверждения приёма. Применение этого разделения к Т18 требует согласования. | N14; F20. |
