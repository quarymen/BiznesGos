# Модель полномочий

Администратор полномочий собирает роли из атомарных прав через интерфейс. Палата, комитет, дело, версия формы и срок задаются при назначении. Фиксированный перечень должностей для этого не нужен. Носителя мандата и его палату подтверждает отдельное основание. Так сохраняется предложенная командой свобода конструктора и личное голосование.

**Решение о доступе.** Для операции ищется хотя бы одно действующее назначение, которое одновременно содержит нужное право и покрывает объект. Затем проверяются состояние объекта, категория доступа, специальные полномочия и запреты. При отсутствии основания действие отклоняется, в журнал попадает причина допустимой детализации. Область одной роли нельзя использовать для расширения прав другой.

| Пример набора | Операции | Область и проверка |
|---|---|---|
| Помощник депутата | Чтение материалов, создание черновика, редактирование версии | Назначенное дело на этапе подготовки. Голосование недоступно. |
| Эксперт | Чтение переданных версий, оформление заключения | Конкретное дело и срок приглашения; без доступа к остальным делам комитета. |
| Руководитель комитета | Постановка поручения, назначение исполнителя, контроль срока | Назначенная руководящая область. Включение дочерних единиц задаётся явно. |
| Депутат ГД / сенатор | Работа с материалами, участие в голосовании | Действующий мандат соответствующей палаты, конкретный вопрос и сессия. Передача голоса помощнику блокируется. |
| Регистратор | Регистрация, классификация, направление | Журнал и подразделение; регистрация не подтверждает принятие акта. |
| Администратор полномочий | Создание версии роли, применение согласованного назначения, отзыв | Изменение набора прав фиксируется. Проектный запрет самоутверждения. |
| Администратор форм | Настройка и публикация утверждённой версии | Только назначенные виды форм. Изменение законодательного маршрута требует содержательного основания. |
| Технический администратор | Обслуживание, контролируемое восстановление | Технический доступ не даёт делового права чтения закрытого дела, голосования или подписания. |
| Контролёр / публикатор | Проверка журнала / выпуск разрешённых версий | Отдельные профили. Публикатор получает точный состав разрешённого пакета. |

## К чему применяется право

| Операция | Объект проверки |
|---|---|
| Редактировать документ | Проверить назначение на документ с учётом его дела, подразделения и статуса. Сохранение создаёт новую версию. |
| Подписать | Проверить полномочие подписанта по выбранной версии. Следующая версия требует отдельного подписания. |
| Поставить вопрос на голосование (PUT_TO_VOTE) | Проверить полномочие организующего процедуру лица по конкретному вопросу. При голосовании по тексту вопрос связан с редакцией. |
| Голосовать (VOTE) | Проверить действующее полномочие участника соответствующей палаты и условия конкретной сессии. Запись в списке приглашённых подтверждает только участие в заседании. |
| Опубликовать | Проверить разрешение для выпускаемой версии и состав публичных сведений. Доступ к полному внутреннему делу проверяется отдельно. |

## Несовместимость

Т6 и таблица 2 документа от 05.11 содержат направленно записанные запреты. Предлагается применять их симметрично к фактическим правам одного лица, включая права из разных ролей и временных назначений. До согласования масштаба запрета использовать буквальный запрет на сочетание у одного лица. Проверять также при изменении состава уже назначенной роли. Ниже сохранены все исходные строки; повтор пары возможен.

| Первая категория | Несовместимые по исходной строке |
|---|---|
| Исполнитель, лицо, принимающее решение (каждая категория отдельно) | Согласующий, контролёр, регистратор, администратор полномочий, технический администратор |
| Контролёр | Исполнитель, согласующий, лицо, принимающее решение, руководитель, администратор полномочий |
| Согласующий | Контролёр, исполнитель, лицо, принимающее решение, руководитель, администратор полномочий |
| Администратор полномочий | Технический администратор, руководитель, контролёр |
| Технический администратор | Администратор полномочий, руководитель, контролёр |
| Регистратор | Исполнитель, согласующий |

**Проверка конструктора.** Создать роль редактирования в комитете А. Назначить тому же лицу чтение в Б. Редактирование в Б должно быть отклонено. Добавление несовместимой операции в роль с действующими назначениями блокируется с перечнем затронутых назначений. При смене созыва архив сохраняет автора решения, прежний мандат больше не даёт права голоса.
