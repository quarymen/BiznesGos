# Электронный документооборот Федерального Собрания РФ

**Учебный проект по бизнес-анализу · редакция для обсуждения от 26 ноября 2026 года.**

Система сопровождает подготовку документов, заседания и движение законодательного дела между палатами. Доказательство прохождения этапа — конкретное решение, подписанная версия либо подтверждение передачи. Настраиваемые роли описывают действия сотрудников внутри этого процесса.

## Как проверить требование

Пример: преподаватель в 11:45 просит проработать отклонение Советом Федерации. [Строка интервью](07-trassirovka.md) ведёт к [F06](04-trebovaniya.md#f06). Его основание — [N07](03-pravila.md#n07), ст. 105 ч. 4–5 Конституции. В [маршруте](05-marshruty.md) есть возврат в ГД и несколько продолжений. На защите можно показать отклонение, постановление СФ и выбор следующего действия. Создание согласительной комиссии требует отдельного решения палат.

Ссылки между файлами работают после распаковки всего каталога. Внешние ссылки ведут к текстам нормативных актов. Материалы команды указаны по названиям файлов.
